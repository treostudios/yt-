# Example public road routing

OpenStreetMap contributors (ODbL, https://www.openstreetmap.org/copyright); separate direction-specific OSRM car-profile responses, geometry only, 5-digit encoded polyline. The video uses this public road connection to explain the border geography, **not** to assert the school district’s itinerary, driveway, lane, travel speed, or stopping procedure. Distances from the responses are not the reported 40-minute school commute.
